# wb2api daemon arm64e-5（2026-11-09 14:25）

## 这一版解决什么

真机日志 352 行全是同一个错：

```
dyld[8542]: Library not loaded: /System/Library/Frameworks/CoreFoundation.framework/Versions/A/CoreFoundation
  Referenced from: …/.jbroot-FE1B2F89EF123789/usr/local/bin/wb2api
  Reason: tried: '…Versions/A/CoreFoundation' (errno=2), … (errno=2, not in dyld cache)
```

根因：Go 按 **macOS 布局**写死了框架路径（`X.framework/Versions/A/X`），
iOS 的 dyld 共享缓存里只有 `X.framework/X`，没有 `Versions/A`。
`Library not loaded` 之后 launchd 的 `KeepAlive` 每 10 秒拉一次，44 次全部同样死法。

受影响的两个依赖：CoreFoundation、Security（crypto/x509 在 darwin 上走系统
验证器，即 SecTrust 那一套）。

> 顺带确认了一个好消息：**平台字段改写 + ad-hoc 签名是通的**。
> 内核和 amfid 都放行了，二进制已经进到 dyld 这一关才失败。

## 从这一版起多的三道保险

1. **CI 门禁 `scripts/verify_macho.py`**
   - `LC_BUILD_VERSION.platform` 必须是 2(IOS)
   - 每个 `LC_LOAD_DYLIB` 必须在 iOS 真实路径白名单里（`Versions/A` 直接红）
   - 签名页哈希逐页复算，`codeLimit == LC_CODE_SIGNATURE.dataoff`

2. **安装期预检（postinst）**
   装完立刻 `wb2api -h` 跑一遍动态链接 + Go runtime 初始化。
   - 通过 → 打印「预检通过（dyld + runtime 正常）」，正常 bootstrap
   - 失败 → 把 dyld 原文打在 `dpkg -i` 的输出里，**并且不启动**（不再无限重启），
     原文同时写到 `…/Library/wb2api/preflight.log`

3. **`wb2api-doctor`**
   一条命令收齐：系统 / 二进制自检 / plist / `launchctl print` / 进程 /
   server.log 末 40 行 / 面板 HTTP 探测 / 数据目录。

## 装法

```sh
dpkg -i com.gan.wb2api_2026.11.9-daemon-arm64e-5_iphoneos-arm64e.deb
```

安装输出里必须能看到这一行：

```
wb2api: 预检通过（dyld + runtime 正常）
```

出任何问题，先跑：

```sh
wb2api-doctor > /tmp/wb2.txt
```

把 `/tmp/wb2.txt` 发回来即可。
