## 二、修的是什么

写完 -24、装到真机上验证时发现：表格转成了卡片（`.as-cards` 生效），但
**卡片里的字段标签整批消失**——`td[data-role]` 一个都没有。

根因：

```js
var pending = false;
function schedule() {
  if (pending) return;
  pending = true;
  requestAnimationFrame(function () { pending = false; sweep(); });
}
```

面板切到后台标签页后 `requestAnimationFrame` **完全暂停**，回调永远不执行，
`pending` 卡在 `true`，之后所有 mutation 都被 `if (pending) return` 丢弃。
表现就是：首屏形状对，切出去看别的再回来、或者面板自己的 5 秒重绘之后，
新渲染的表格再也不会被打标。

改成 `setTimeout(…, 30)`：后台标签页里定时器只是降频（约 1 秒一次），不会停。

## 四、审计方法（可复现）

每个视图按表头灌对抗性数据（超长 UA、UUID、7 位数、空值、按钮），逐元素量：

1. 横向溢出（排除滚动容器内元素）
2. 文本裁切（`scrollWidth > clientWidth` 且 `overflow != visible`）
3. 触摸目标 < 34px
4. 文字对比度 < 3.6（背景必须取**不透明**祖先，半透明底会产生 1.17 这种误报）

第 4 条的背景解析是这轮踩的坑：`rgba(0,0,0,0.03)` 这类斑马纹若被当成纯黑，
深色字就会算出 1.17:1，误判成「看不见」。必须先做 alpha 混合或跳过半透明层。
