# 交付说明 · 2026.11.14-daemon-arm64e-29

用**真实数据**复检后的收口版本。前四版（-24..-28）是迭代过程，这一版是验收态。

## 一、为什么之前"看起来没问题"

-24/-25 的复检用的是按表头造的假数据：短、规整、每格一行。
真实数据一进来（6 个账号、26179 积分、39 行表格、请求事件 100 行、日志 201 行），
三类问题立刻暴露：说明字对比度、图例溢出、宽表卡片过高。

## 四、测量方法上的三条坑（都写进脚本了）

1. **切主题后必须等过渡结束**（约 2.5s）再量，否则量到的是中间色，
   会出现 2.49:1 这种不存在的"缺陷"。
2. **背景必须按层混色**：`rgba(0,0,0,0.03)` 的斑马纹若当纯黑算，深色字能算出 1.17:1。
3. **`text-overflow:ellipsis` 的截断是设计**（带 title 提示），不算裁切缺陷。
